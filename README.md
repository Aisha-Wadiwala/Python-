# 🎯 Number Guessing Game

A beginner-friendly Python game where the computer generates a random number and the player tries to guess it.

## 🛠️ Concepts Used

* Python basics
* `random` module
* `if-else` statements
* `while` loops
* User input
* Variables

## 🎮 How to Play

Run the Python file and enter your guesses. The game gives hints to help you determine whether your guess is too high or too low.

## 🚀 Purpose

This project was created to practice Python fundamentals and improve problem-solving skills.
